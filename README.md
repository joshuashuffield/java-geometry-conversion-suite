# Multi-Function GUI Geometry & Unit Conversion Suite
A modular desktop application built in Java using the Swing framework. Features 2D/3D geometric surface
area calculators and real-time unit conversion engines.
## Key Features
- **2D Geometry Engines**: Real-time calculation of area for Circles, Squares, and Triangles.
- **3D Geometry Engines**: Real-time calculation of surface area and volume for Cylinders, Cubes, and
Rectangular Prisms.
- **Unit Conversions**: Real-time calculation modules for Time, Currency, Temperature, and Volume
conversions.
- **GUI Architecture**: Event-driven navigation built using `JFrame`, `ActionListeners`, and
asynchronous `EventQueue` dispatching.
- **Input Validation**: Robust `try-catch` exception handling and boundary checks to prevent runtime
errors from invalid or negative inputs.
## Technologies Used
- **Language**: Java
- **Framework**: Java Swing (GUI)
- **Concepts**: Object-Oriented Programming (OOP), Event Handling, Input Parsing, Multi-Window
Architecture
